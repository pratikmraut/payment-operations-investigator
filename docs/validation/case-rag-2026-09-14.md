The normal Case queue now opens Payment cases directly, with no Demo cases switch. New case questions use the local Ollama case pipeline from both the saved case and Evidence Q&A pages. Historical synthetic cases, Replay fixtures and the original standalone export answer implementation remain preserved outside normal navigation.

## Scope and architecture

This changes retrieval, prompting, validation and presentation around the existing Qwen3 8B model. It does not train model weights. See [the architecture and demonstration guide](../CASE_RAG.md) for the flow and exact limits.

Java freezes the authorized evidence version and guidance in a durable job. The worker ranks the supplied guidance with lexical BM25, retains every supplied source, checks context size and asks Ollama for cited claims, unknowns and next checks. Code validates citations and recognizable explicit native field quotations. A first validation failure permits one model-generated correction using the same question and sources; a second invalid result fails. Java rechecks the response before saving it. No model wording is replaced with a prepared answer.

The default engine is `CaseRagEngine`. An earlier experiment requiring the model to generate separate field-support objects failed live validation and is retained only as an optional experiment. It is not the serving path.
